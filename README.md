# 秋招投递管理器

一个面向秋招求职者的投递管理工具，可在电脑浏览器和手机上使用。无需注册账号，投递数据默认只保存在使用者自己的浏览器中。

## 普通用户请从这里开始

**[打开简洁下载中心](https://songxue0614-lgtm.github.io/autumn-recruitment-tracker/download.html)**

下载中心只有三个选择：在线使用、下载电脑离线版、下载浏览器插件。普通使用者不需要理解仓库里的技术文件。

## 立即使用

**在线网页版：** [打开秋招投递管理器](https://songxue0614-lgtm.github.io/autumn-recruitment-tracker/)

- 电脑：推荐使用 Chrome、Edge 或 Safari 直接打开。
- iPhone：使用 Safari 打开后，点击“分享” → “添加到主屏幕”。
- Android：使用 Chrome 打开后，点击“安装到手机”或“添加到主屏幕”。

## 主要功能

- 新增、编辑、删除投递记录，并一键推进招聘阶段
- 记录公司、岗位、城市、投递日期、当前阶段、最近安排和下一步行动
- 今日投递统计、搜索、阶段筛选、排序、彩色阶段分布和未来安排
- 浏览器本地自动保存、历史快照、JSON 导入与导出备份
- 直接粘贴或批量选择岗位截图，在浏览器本地 OCR 识别并人工校对
- 使用“秋招一键收录”插件识别已打开的招聘网页
- 支持安装到 iPhone、Android 手机桌面，像普通 App 一样打开

## 数据与隐私

- 每位使用者的数据独立保存在自己的浏览器中，其他人无法看到或修改。
- 网页更新不会主动覆盖已有投递记录。
- 电脑与手机、不同浏览器之间**不会自动同步数据**。
- 换设备时，请先“导出数据”，再在新设备的“数据安全”中导入 JSON。
- 清理浏览器网站数据、使用无痕模式或卸载浏览器可能造成记录丢失，请定期导出备份。

## 本地离线版

下载并解压完整离线包后，双击 `index.html`。请勿单独移动 `index.html`，它需要同目录中的 `ocr`、`icons`、`manifest.webmanifest` 和 `service-worker.js`。

## 版本

- 网页：v3.0.0
- 浏览器插件：v1.4.2
- 数据存储标识：`autumnRecruitmentTracker.records.v1`

更新功能时必须保留数据存储标识，并兼容旧字段，避免用户升级后找不到原有记录。
