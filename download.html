获取浏览器插件

「秋招求职与简历助手」安装到电脑 Chrome 或 Edge：完整功能在浏览器侧边面板里——网申页简历字段点击速填（左键填入聚焦框、右键复制、可搜索）、一键收录岗位进投递台账，未打开管理器时先进暂存箱。侧边面板由浏览器管理、不遮挡网页，可以一边看表单一边点字段填入；页面上另有一个可拖拽的收录胶囊，点它弹出紧凑表单，拖到页面空白处就不挡内容，位置会记住。纯离线、不发起任何网络请求。手机浏览器不能安装插件。

插件 v5.5.0 · 侧边面板需 Chrome / Edge 114 或更新（更低版本仍可用页面胶囊收录）· 直接下载压缩包，解压后加载

下载插件压缩包（.zip）

安装时只需要记住

手机：iPhone 用 Safari 打开网页版后“添加到主屏幕”；Android 用 Chrome 选择“安装应用”。

插件：点上方“下载插件压缩包”→ 解压得到 extension 文件夹 → 打开 edge://extensions（或 chrome://extensions）开启“开发者模式”→“加载已解压的扩展程序”→ 选中解压出的 extension 文件夹（含 manifest.json）→ 点浏览器工具栏上的扩展图标（或按 Ctrl/⌘+Shift+F）打开侧边面板。以后更新：重新下载解压，在扩展页点“重新加载”。
