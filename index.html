云同步（GitHub Gist）

开启后，投递记录会自动同步到你 GitHub 账号下的私有 Gist；手机和电脑填同一个令牌，数据即可互通。设置口令后，数据先在本机加密再上传，GitHub 只保存密文；不同口令对应不同数据空间，互不覆盖，可随时切换。

令牌只保存在本机浏览器，不会发给 GitHub 以外的任何服务；生成方法见下方说明。

怎么生成访问令牌？
  1. 电脑登录 GitHub → 右上角头像 → Settings。
  2. 最底部 Developer settings → Personal access tokens → Tokens (classic)。
  3. Generate new token (classic)：只需勾选 gist 一个权限，生成后立即复制令牌（页面关闭后无法再查看）。
  4. 回到本页粘贴令牌，设置口令后点击“保存并同步”；另一台设备重复同样操作即可互通。

安装到手机桌面

请先通过 GitHub Pages 的 HTTPS 地址打开。安装后会像普通 App 一样从桌面启动，投递数据仍只保存在当前手机浏览器中。

  1. iOS
    iPhone / iPad使用 Safari 打开网页 → 点击底部“分享” → 选择“添加到主屏幕” → 点击“添加”。
  2. 安卓
    Android使用 Chrome 打开网页 → 点击右上角菜单 → 选择“安装应用”或“添加到主屏幕”。
  3. 备份
    换手机前先导出不同手机不会自动同步数据。请先点击“导出投递记录”，再在新手机的“数据安全”中导入。
