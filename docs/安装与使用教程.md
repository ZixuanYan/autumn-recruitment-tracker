# 秋招投递管理器｜安装与使用教程

在线地址：<https://zixuanyan.github.io/autumn-recruitment-tracker/>

## 一、电脑网页版

1. 使用 Chrome、Edge 或 Safari 打开在线地址。
2. 无需注册，进入后即可新增投递记录。
3. 建议收藏网页，后续固定使用同一个浏览器打开。

网页会自动保存新增、编辑、删除和推进阶段后的数据。刷新网页通常不会丢失记录。

## 二、电脑离线版

1. 从项目首页下载“秋招投递管理器-电脑离线版-v3.0.0.zip”。
2. 双击 ZIP 完成解压。
3. 打开解压后的文件夹，双击 `index.html`。
4. 不要只复制 `index.html`；截图识别还需要同目录中的 `ocr` 文件夹。

本地版与在线版属于两个不同网站，数据不会自动互通。切换版本时请使用“导出数据”和“导入备份文件”。

## 三、iPhone 安装

1. 使用 Safari 打开在线地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点击右上角“添加”。
5. 返回桌面，点击“秋招管理”图标。

如果链接在微信中打开，请先通过右上角菜单选择“在 Safari 中打开”。

## 四、Android 安装

1. 使用 Chrome 打开在线地址。
2. 点击网页中的“安装到手机”；如果没有显示，打开 Chrome 菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 确认后从手机桌面打开。

## 五、浏览器插件安装（仅电脑）

1. 下载“秋招一键收录插件-v1.4.2.zip”。
2. 双击 ZIP，将插件解压为普通文件夹。
3. Chrome 地址栏输入 `chrome://extensions/`；Edge 输入 `edge://extensions/`。
4. 开启右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择包含 `manifest.json` 的插件文件夹，不要选择 ZIP 文件。
7. 安装后建议通过浏览器右上角的拼图图标固定插件。

使用电脑本地版时，还要在插件“详情”中开启“允许访问文件网址”。在线网页版一般不需要开启这项权限。

### 插件使用

1. 打开招聘网站的岗位详情页或投递记录页。
2. 点击工具栏中的“秋招一键收录”。
3. 点击识别或收录当前页面。
4. 管理器打开后，检查公司、岗位、城市、日期和阶段。
5. 确认无误后保存。

招聘网站结构可能改变，插件识别结果必须在保存前人工核对。手机浏览器不能安装此插件。

### 插件更新

1. 下载并解压新版插件。
2. 使用新版文件替换旧插件文件夹。
3. 回到扩展程序管理页面。
4. 点击插件卡片上的“重新加载”。
5. 刷新招聘网页和投递管理器。

## 六、基本使用

- “新增记录”：填写公司、岗位、城市、投递日期、当前阶段、安排和下一步行动。
- “推进”：将记录推进到下一个招聘阶段。
- “编辑/删除”：修改或移除记录。
- “搜索与筛选”：按公司、岗位和阶段查找记录。
- “截图识别”：直接粘贴截图，或一次选择多张图片，识别后先校对再导入。
- “导出数据”：下载带日期的 JSON 备份，不会修改现有记录。
- “数据安全”：导入备份、恢复数据或查看本地快照。

## 七、重要说明

- 网页功能更新后，设备会逐步获取新版本。
- 投递记录不会在电脑和手机之间自动同步。
- 同一网址在不同设备、不同浏览器中也是独立数据。
- 需要换设备时，请将旧设备导出的 JSON 文件传到新设备，再在新设备中导入。
