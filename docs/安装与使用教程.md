# 秋招投递管理器｜安装与使用教程

在线地址：<https://zixuanyan.github.io/autumn-recruitment-tracker/>

## 一、电脑网页版

1. 使用 Chrome、Edge 或 Safari 打开在线地址。
2. 无需注册，进入后即可新增投递记录。
3. 建议收藏网页，后续固定使用同一个浏览器打开。

网页会自动保存新增、编辑、删除和推进阶段后的数据。刷新网页通常不会丢失记录。

## 二、iPhone 安装

1. 使用 Safari 打开在线地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点击右上角“添加”。
5. 返回桌面，点击“秋招管理”图标。

如果链接在微信中打开，请先通过右上角菜单选择“在 Safari 中打开”。

## 三、Android 安装

1. 使用 Chrome 打开在线地址。
2. 点击网页中的“安装到手机”；如果没有显示，打开 Chrome 菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 确认后从手机桌面打开。

## 四、浏览器插件安装（仅电脑）

1. 获取插件「秋招求职与简历助手」（v3.2.0）：克隆或下载本仓库后，插件源码位于 `extension/` 目录；也可在线查看 <https://github.com/ZixuanYan/autumn-recruitment-tracker/tree/main/extension>。
2. Chrome 地址栏输入 `chrome://extensions/`；Edge 输入 `edge://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择仓库里的 `extension/` 文件夹（其中含 `manifest.json`），不要选择 ZIP 文件。
6. 安装后建议通过浏览器右上角的拼图图标固定插件。

在线网页版一般不需要开启插件的“允许访问文件网址”权限。

### 插件使用

1. 打开招聘网站的岗位详情页或投递记录页。
2. 点击页面右侧胶囊“简历助手”，或按 Ctrl/⌘+Shift+F 打开侧边栏。
3. 点击“一键收录当前岗位”收录岗位；若要填表，先点网页里的输入框，再点侧栏对应的简历字段即可填入（**右键**字段可复制内容，顶部搜索框可按字段名/内容过滤）。
4. 管理器打开后，检查公司、岗位、城市、日期和阶段。
5. 确认无误后保存。

招聘网站结构可能改变，插件识别结果必须在保存前人工核对。手机浏览器不能安装此插件。

### 插件更新

1. 下载并解压新版插件。
2. 使用新版文件替换旧插件文件夹。
3. 回到扩展程序管理页面。
4. 点击插件卡片上的“重新加载”。
5. 刷新招聘网页和投递管理器。

## 五、基本使用

- “新增记录”：填写公司、岗位、城市、投递日期、当前阶段、安排时间、**截止日期**和下一步行动；展开“更多字段”可再填**批次 / 渠道 / 内推人 / 意向度 / 薪资**。
- “推进”：弹出选择要推进到的阶段（可跳过笔试、可三/四/五面、可自定义），追加为该投递的时间线里程碑；当前阶段 = 最新里程碑。
- “看板视图”：台账面板右上角“表格 | 看板”切换；看板按阶段分列，**把卡片拖到目标列即等于推进阶段**（同样追加里程碑），往更早的阶段拖会二次确认。偏好记在本机。
- “详情抽屉”：点台账里的**公司名**、看板卡片、未来安排卡片或洞察里的卡点条目，右侧滑出详情——完整里程碑步骤条（含每步间隔天数）、关键信息、**笔记 / 面经**（可增删）、同公司其它投递，底部可直接推进 / 编辑 / 导出该记录到日历 / 删除。
- “编辑/删除”：修改或移除记录（删除可在提示条里撤销）。
- “搜索与筛选”：按公司、岗位和阶段查找记录；排序支持“最近安排优先 / 投递日期 / 最近更新 / 公司名称 / **按公司聚合**”。
- “同公司多岗位”：一家公司投多个岗位、或同一岗位投了提前批与正式批，都能分开记录（用“批次”区分）。公司名旁出现 `+N 岗位` 标记（悬停看各岗位与阶段）；选“按公司聚合”排序后同公司相邻，组头可折叠。查重规则为“同链接”或“同公司 + 同岗位 + 同批次”才算重复。
- “洞察”：总览自动算出转化漏斗（投递 → 笔试/测评 → 面试 → Offer，可切换记录口径 / 公司去重口径）、近 14 天投递节奏、各阶段平均停留天数、覆盖公司数与停滞条数，以及“需要关注”清单（截止临期或逾期、安排已过但阶段未推进、停滞超 14 天、同公司多岗位在流程中）。全部在浏览器本机计算，不上传、不联网。
- “Offer 对比”：手里有 2 个及以上 Offer 时，洞察面板自动出现对比矩阵（公司 / 岗位 / 城市 / 薪资 / 意向度 / 签约截止 / 最新备注），按意向度排序。
- “截止日期与日历”：填了截止日期的记录会在台账显示倒计时（3 天内黄、逾期红），并与面试安排一起进入“未来安排”（逾期置顶）。点“导出日历”或工具页“导出 .ics 日程”，生成的 `.ics` 文件双击即可加入系统日历（本机生成，不联网）。
- “快捷键”：`⌘K` / `Ctrl+K` 打开命令面板（搜记录、跳页面、执行动作）、`N` 新增投递、`/` 聚焦台账搜索、`?` 打开面板看提示、`Esc` 关闭抽屉或弹窗、抽屉笔记框里 `⌘` / `Ctrl` + `Enter` 快速提交。
- “截图识别”：直接粘贴截图，或一次选择多张图片，识别后先校对再导入。
- “导出投递记录”：下载带日期的 JSON 备份（含投递记录与简历），不会修改现有记录。
- “数据安全”：导入备份、恢复数据或查看本地快照。

> 首次打开时台账里会有 5 条示例数据（星海科技、山岚智能、青禾互娱、远帆咨询、拾光设计），只用于认识界面。洞察位置的引导卡提供“清空示例并开始记录”（清空会写删除标记，即使已开云同步也不会被合并回来）；示例数据也绝不会参与云同步合并，不会被推到你的 Gist 里。

## 六、邮件提醒（可选，自动解析招聘邮件）

「邮件提醒」视图（左侧导航第 5 项，`#/mail`）把你 QQ 邮箱里的招聘邮件（面试 / 笔试 / 测评 / Offer / 拒信）解析成结构化建议，逐项人工复核后并入台账。它依赖一个你自己部署的定时任务，默认不开启。

启用步骤（进阶，需要一个 GitHub 账号）：

1. 先在「工具 → 云同步」开启云同步——邮件建议随云同步从你自己的私有 Gist 读取。
2. 在 GitHub 新建**私有**仓库 `autumn-mail-sync`，放入配套脚本（IMAP 拉取 + AI 解析 + 只写 Gist 的 `mail-suggestions.json`）。
3. 在 QQ 邮箱开启 IMAP 并生成 16 位授权码；准备一个 DeepSeek / 阿里百炼 API Key；拿到云同步用的 Gist ID 与一个 `gist` 权限的访问令牌。
4. 在该私有仓库的 Secrets 配置 `QQ_EMAIL`/`QQ_AUTHCODE`/`AI_BASE_URL`/`AI_API_KEY`/`AI_MODEL`/`GIST_ID`/`GIST_PAT`；先手动跑 `connectivity-test` 验证能登录，再启用每小时定时任务 `mail-sync`。
5. 回到网页「邮件提醒」点「重新读取」，即可看到建议（导航角标显示待复核数量）。

复核与应用：

- 每张建议卡按公司名模糊匹配你的台账：命中 1 条直接显示、命中多条让你选、没命中可「新建记录」预填邮件信息。
- 勾选要采纳的字段（推进里程碑 / 安排时间 / 最近安排 / 下一步行动），点「应用所选」写入；点「忽略」则本机不再显示。
- **所有更新都要你手动确认，绝不自动写入**；置信度低（<0.6）的建议会标黄，请仔细核对后再应用。

设置、加密与跨设备（v4.3.0）：

- **跨设备同步**：在某台设备「忽略 / 应用」过的邮件建议，会随云同步到其它设备，不再重复出现，无需逐台点击。
- **网页端设置**：视图右上「设置」可调预筛关键词、置信度阈值、回看天数、单次上限、**启用开关**、**最小运行间隔**、以及 **AI 附加指令**（如"只关注互联网/国企"）。保存后写入你自己 Gist 的 `mail-config.json`（明文、不含密钥），Action 下次运行读取生效；关闭开关或间隔未到时 Action 直接跳过、**0 token**。
- **邮件加密（可选，推荐）**：Action 侧配置 `MAIL_ENC_KEY` Secret 后，`mail-suggestions.json` 会加密存储；在网页「设置 → 邮件解密密钥」填**完全相同**的密钥（可点「生成」再复制到 Secret）即可解密查看。密钥只存本机，不上传 Gist。这样即便有人拿到你的 Gist 链接也读不到明文（GitHub 的 secret gist 凭链接本可被访问）。
- 密钥类（QQ 授权码 / AI Key / GIST_PAT / MAIL_ENC_KEY）永远只在你的私有仓库 Secrets 与本机，不会进网页、不会进台账数据。

隐私与注意：

- QQ 授权码、AI Key、Gist 令牌只存在你的私有仓库 Secrets，永不进浏览器、不进网页本地存储。
- 邮件正文只发往你自己配置的 AI 端点；建议结果明文存在你自己的私有 Gist。
- 改过 QQ 密码后授权码会失效，视图顶部会红条提示并附「怎么修复」；重新生成授权码并更新 Secret 即可。
- 「已应用 / 已忽略」只记在本机，不跨设备同步。

## 七、重要说明

- 网页功能更新后，设备会逐步获取新版本。
- 投递记录不会在电脑和手机之间自动同步。
- 同一网址在不同设备、不同浏览器中也是独立数据。
- 需要换设备时，请将旧设备导出的 JSON 文件传到新设备，再在新设备中导入。
