# 快速上手指南（新用户 5 分钟）

> 面向第一次使用「秋招投递管理器」的同学，看完就能开始记录投递。更详细的安装 / 数据说明见文末链接。

## 这是什么

一个**免费、免注册**的秋招投递管理网页：记录你投了哪些公司 / 岗位、走到哪一步（笔试 / 面试 / Offer）、下一步做什么。数据默认**只存在你自己的浏览器里**，别人看不到、作者也看不到。

## 三步开始

1. **打开网页**：<https://zixuanyan.github.io/autumn-recruitment-tracker/>（电脑用 Chrome / Edge / Safari，手机也能打开）
2. **点右上「新增投递」**：填公司、岗位、城市、投递日期、当前阶段 → 保存。
3. 完成。数据已自动存在本机，之后随时回来更新阶段、看统计。

无需注册、无需下载安装、无需数据库。

## 四个要点（务必知道）

- **数据在你本机**：默认只存当前浏览器。清理浏览器数据、用无痕模式、换设备都可能丢失 → 请定期用「工具 → 数据安全 → 导出投递记录」下载 JSON 备份。
- **阶段是「里程碑时间线」**：点记录里的「推进」选下一阶段（可跳过笔试、可三 / 四 / 五面、可自定义），会追加为一条里程碑，当前阶段 = 最新一条。
- **「完成」与「推进」是两件事**（v4.18.0）：测评 / 笔试这类**任务**做完了，不代表进入下一步。点「标记完成」只给当前这一步打勾（卡片显示「已完成 · 待推进」，表格「最近时间」列出现绿色「已完成」徽章），不推进、不换列；完成后不再算「停滞」、不再出现在「需要关注」里（v4.27.0 起「已完成 N 天，考虑推进」提醒也已移除——已完成的事不再催你，想起来了就推进）。随时可取消，编辑记录时也能逐条勾选。
- **做完的事不再催你**（v4.23.0，v4.27.0 扩展）：标记完成、或流程已推进到更晚的里程碑之后，那条时间不再出现在「未来安排」和「需要关注」里（此前已完成的面试会一直以“逾期”置顶）。**当前阶段标记完成时，名下的截止时间也一并了结**——「已完成网申投递」之后就不会再有「网申截止还剩 2 天」的倒计时（v4.27.0）；推进到下一阶段后，新阶段的截止自动恢复提醒。
- **同一家公司投了多个岗位**：岗位名里把区分信息写进括号即可分别记录，例如 `后端开发工程师（深圳）` 和 `后端开发工程师（北京）`、`客户端开发（iOS）` 和 `客户端开发（Android）`、`产品经理（提前批）` 和 `产品经理（社招）`。填公司名时下方会实时显示「该公司已有 N 个岗位」；遇到相近岗位会问一句「是不同方向/城市的独立投递吗」，选「是独立投递，新增」即可。
- **换设备 / 多设备**：两种方式——① 导出 JSON，再在新设备「数据安全 → 导入备份」；② 开启「工具 → 云同步」，用**你自己的** GitHub 令牌把数据同步到**你自己的**私有 Gist（可设口令加密，跨设备互通）。

## 用得更快

- **看板视图**：在「投递记录」页右上角「表格 | 看板」切换。看板从上到下是 **Offer 横带 → 推进投放区 → 进行中阶段列 → 已结束横带**（v4.17.0 起 Offer 与已结束不再各占一列常年空着），**把卡片拖到目标列或横带就等于推进阶段**（会追加一条里程碑，历史不会被覆盖）；往回拖会二次确认。Offer 横带下方还有一条整宽**推进投放区**：把卡片拖进去可**自由选择推进到的阶段**（含三面 / 交叉面这类当前没有列的阶段，会复用推进弹窗，可填备注、改日期）；拖到「已结束」列会引导你填结束原因（拒信 / 主动放弃 / 超期未响应）。停滞超 14 天的卡片会标红并显示「停滞 N 天」，点列头可按该阶段筛选到表格视图。键盘用户聚焦卡片按 `A` 也能打开推进弹窗。
- **详情抽屉**：点表格里的**公司名**（或看板卡片、未来安排卡片）从右侧滑出，能看到完整里程碑步骤条（每步之间隔了几天）、关键信息、**笔记 / 面经**，以及同一家公司的其它投递。
- **洞察**：总览上方自动算出「需要关注」清单（截止临期 / 逾期、安排过了但阶段没推进、停滞超 14 天）、转化漏斗（投递 → 笔试测评 → 面试 → Offer）、**阶段分布**（当前存量按阶段计数，与漏斗同排；v4.8.0 从总览的独立面板并进了洞察）、近 14 天投递节奏、各阶段平均停留天数。全部在你浏览器里算，不上传。面板右上角可切**「精简」**，只留概览数字、需要关注、漏斗与阶段分布，把明细折起来（偏好记在本机）。
- **城市分布 / 企业性质**（v4.6.0）：洞察里能看到「投了哪些城市、各城市投了多少、拿到几个 Offer」，以及央国企 / 私企 / 外企的占比与各自 Offer 数。企业性质要在记录里选一次（新增 / 编辑弹窗的「企业性质」，插件一键收录时也能直接选），没选的会归到「未设置」并在说明里提醒你补填。城市名会自动归一（`深圳市` = `深圳`），`待确认 / 不限` 这类占位值算「没填城市」；一条记录写了多个城市（`深圳/广州`）会在每个城市各计一次。
- **悬浮看明细**（v4.6.0）：鼠标停在指标卡上看**口径说明**（例如「停滞」到底按投递日期还是最新里程碑算），停在城市行上看**该城市的每条投递**，停在企业性质的色段上看**该档的公司清单**。键盘 `Tab` 聚焦也能弹出，`Esc` 关闭；手机上点一下即可。
- **关键时间要分类填（v4.19.0，v4.24.0 起两类分组）**：一条记录可以填**多个**时间，下拉按**截止时间**（必须赶的硬期限，台账显示倒计时）与**开始时间**（**面试** / **笔试测评** / **其他**）分组。**类型只是标签**——一条时间是「只有日期」还是「精确到分」，取决于你**填不填时刻**：所以**截止也能填到分钟**（v4.24.0），邮件里写的「9 月 17 日 18:00 前」不会再被削成 `9/17`，倒计时在最后 24 小时会按小时播报（「还剩 3 小时」）。点「＋ 添加时间」加一条，行内可改类型 / 日期 / 时刻 / 删除。旧的「安排时间 / 截止日期」会在读取时自动迁成带类型的事件，老记录不用动。
- **邮件里的「3 日内 / 48 小时内」（v4.24.0）**：这类**相对表达**由 AI 按**收信时刻**换算成绝对截止时间，卡片上会标一枚蓝色**「按邮件推算」**（悬停看得到邮件原文表达）——看到它就多核对一眼，因为算出来的日期看起来和邮件里写死的没区别。换算用的时区由 Action 仓库的变量 `MAIL_TZ_OFFSET` 决定（默认 `+08:00`）。
- **同公司多岗位**：一家公司投多个岗位都能分开记，区分信息写进岗位名的括号里即可（「后端开发（深圳）」与「后端开发（北京）」）；同一家企业的不同分行 / 子公司 / 事业部用**「机构」字段**区分（v4.11.0 起接替已删除的「批次」）。公司名旁会出现 `+N 岗位` 标记。
- **同企业收纳（v4.11.0，v4.25.0 起组头是卡片）**：表格上方的独立开关（不再是排序选项，所以和四种排序都能叠加）。打开后同一家公司收进一个组，组头是一张**公司卡片**——公司名 + 岗位数 + 一排**岗位胶囊**（岗位 + 阶段），折叠时不用展开就能看清这家每个岗走到哪一步，胶囊可点开详情、悬浮看明细。机构不单独成层，它标在每一行的公司名后面（`招商银行 · 杭州分行`）。组多了懒得逐个点：开关旁有一个**一键折叠按钮**（v4.26.0，只在收纳打开时出现）——还有展开的组时显示「全部折叠」，全折叠好了就变「全部展开」；它只动**当前筛选出来的**那些组。
- **最近时间的红字（v4.26.0）**：台账「最近时间」列里，**已经推进过去**的安排仍会显示日期，但转成灰色、不再标「已过期」——做完了的事不该天天亮红灯；**没人处理**的逾期才保留红字 +「已过期」。同一天推进（一面 9/12、二面也填 9/12）不算「走过它」，那天仍会报逾期，用「标记完成」消除。
- **邮件里的测评链接（v4.26.0）**：笔试 / 测评邮件里那条「点击开始测评」的地址，现在会**单独抽出来**跟着记录走——打开记录详情 →「相关邮件」，就有一排**可点的地址胶囊**，点一下直接跳过去，不用回邮箱翻。链接是代码从邮件里抽的（不是 AI 猜的），只认 `http/https`，退订之类的模板链接会被丢掉；邮件原文里的地址也会自动变成可点链接。**旧邮件补不回来**（那封邮件早已越过水位线，Action 不会再解析它），想让它们也有链接得按教程里的办法回溯重扫一次。另外，链接常带一次性 token，它和正文一样会随归档进 Gist（没设同步口令时是明文）。

## 可选增强（不影响基本使用）

### A. 手机装到桌面（像 App 一样打开）

- iPhone / iPad：用 **Safari** 打开网页 → 分享 → 「添加到主屏幕」。
- 安卓：用 **Chrome** 打开 → 「安装到手机」或「添加到主屏幕」。
- 微信里打开的链接，请先用右上角菜单选「在浏览器 / Safari 中打开」。

### B. 浏览器插件（仅电脑，网申更省事）

「秋招求职与简历助手」：完整功能在**浏览器侧边面板**里（点工具栏的插件图标，或按 Ctrl/⌘+Shift+F）——**点简历字段即速填**（左键填入光标所在框、右键复制、顶部可搜索）、**一键收录岗位**进台账、查看与清理暂存箱。侧边面板**不遮挡网页**（页面变窄而不是被盖住），可以一边看网申表单一边点字段填入。没打开管理器时先进暂存箱。**纯离线、不发起任何网络请求**（v5.6.0 起页面上不再有任何插件注入的按钮，收录入口统一在面板里）。v5.7.0 起识别更准：低可信来源黄标提醒、列表页会提示先进详情、iframe 里的详情可扫，**改正过的公司名按网站记住、下次自动套用**（面板最下方「识别纠正记忆」可导出 / 导入）。

安装：获取 `extension/` 文件夹 → 浏览器扩展页（`edge://extensions` 或 `chrome://extensions`）开启「开发者模式」→「加载已解压的扩展程序」→ 选中 `extension/` 文件夹 → 用工具栏的拼图图标固定插件，之后点它就能打开侧边面板。侧边面板需 Chrome / Edge 114+（更低版本无法使用插件界面，请先升级浏览器）。手机浏览器不能装插件。

### C. 邮件提醒（进阶，可选，需要一点动手能力）

让招聘邮件（面试 / 笔试 / 测评 / Offer / 拒信）自动解析成建议，在网页逐项复核入账。需要你自己 fork 一个 GitHub Action 模板、填**你自己的**邮箱授权码 / AI Key（**全程用你自己的账号，作者不经手你的任何密钥**）：

1. 打开模板仓库 <https://github.com/ZixuanYan/autumn-mail-sync-template>，点「Use this template」创建**你自己的私有仓库**（务必设为 private）。
2. 按该仓库 README 配置 Secrets（邮箱授权码、AI Key、你的 Gist ID 与令牌等；QQ 与 163/126 都支持，非 QQ 邮箱另设 `IMAP_HOST` Variable），先跑一次连通性测试。
3. 回到本网页开启云同步，「邮件提醒」页面点「重新读取」即可看到建议。

不配置这一项**完全不影响**前面所有功能；邮件提醒页面此时会提示"需先开启云同步 / 暂无建议"。

配好之后如果**怀疑漏了某封邮件**：状态栏会显示本次「丢弃 N 封」，展开能看到每封被丢邮件的发件人、主题、邮件编号和丢弃原因（自动预筛必然要丢东西，关键是丢得可查）。确认是误丢，就按提示用邮件编号回溯重扫一次；若丢弃原因总是「没命中关键词」，在「邮件提醒 → 设置」里给关键词补词即可。招聘系统常用的 `noreply` 类发件人不会被当成营销邮件丢掉，主题写着「面试邀请 / 笔试通知」的邮件会直接放行进 AI 判定。

想调 AI 的解析行为（v4.7.0）：设置面板里能**直接看到 Action 实际发给 AI 的完整提示词**（不是副本，是生效的那一份），也可以用「整体替换解析提示词」完全定制，清空即恢复内置。只有末尾的「输出契约」改不掉——它保证 AI 返回的内容能被程序解析，删了的话建议队列会永远为空却仍显示成功。另外建议卡上的里程碑备注，类型明确时显示「邮件·测评」这类短标签，类型是「其它」时改用 AI 写的内容摘要（如「简历成功投递滴滴校招，等待后续流程推进」），这条备注勾选后会写进台账时间线，所以要有信息量。

## 常见问题

- **要注册或付费吗？** 不用，全免费、无账号。
- **别人能看到我的投递吗？** 不能。数据在你浏览器；即使开云同步，也只进你自己的私有 Gist（可加密）。
- **记录会不会丢？** 只存本机时有风险，请务必定期导出 JSON 备份；开云同步可跨设备并防丢。
- **手机能用插件吗？** 不能，手机浏览器不支持扩展；但网页本身在手机上完整可用（含看板、洞察、云同步）。
- **同时投很多家怎么不乱？** 用「投递记录」页的搜索 / 阶段筛选 / 排序，配合日历页的「未来安排」与月历跟进面试时间。
- **同一家公司投了两个岗位，第二个录不进去？** v4.5.0 起已修好：把区分信息写进岗位名的括号里（城市 / iOS-Android / 提前批-正式批），弹出「是不同方向/城市的独立投递吗」时选「是独立投递，新增」。若你用的是旧版本，刷新页面即可（或强制刷新 Cmd+Shift+R 清缓存）。
