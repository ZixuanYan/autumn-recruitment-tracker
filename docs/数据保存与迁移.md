# 数据保存、迁移与常见问题

## 数据保存在哪里？

投递记录保存在当前设备、当前浏览器的网站本地存储中，不会自动上传到 GitHub，也不会被其他使用者看到。

## 为什么在线版没有本地版的数据？

浏览器会把 `file://` 本地文件和 `https://` 在线网页视为两个不同网站，它们无法直接读取彼此的数据。

迁移方法：

1. 在有记录的旧页面点击“导出数据”。
2. 打开准备长期使用的新页面。
3. 进入“数据安全”并点击“导入备份文件”。
4. 选择刚才导出的 JSON 文件。

## 为什么电脑导入后，手机仍然没有数据？

电脑和手机是两个独立设备。必须把 JSON 文件发送到手机，并在手机准备长期使用的浏览器或桌面 App 中再次导入。

## 电脑与手机能自动同步吗？

默认不会自动同步（数据只保存在各自设备）。如需跨设备同步，可在「工具 → 云同步」填入自己的 GitHub 访问令牌开启可选云同步（支持口令加密）；开启后各设备打开页面时会自动拉取/推送最新的投递记录与简历。不开启云同步时仍为本地隐私模式。

## 哪些情况可能丢失数据？

- 清理浏览器的网站数据或缓存时同时删除存储
- 使用无痕/隐私浏览模式
- 换浏览器、换设备或重装浏览器
- 长期只依赖单一设备而从不导出备份

## 推荐的备份习惯

- 每周至少导出一次 JSON。
- 面试安排集中变化时额外导出一次。
- 将备份文件放在自己的云盘、电脑文档目录或移动硬盘中。
- 导入旧备份前先导出当前数据，避免误覆盖。

## 多人共用同一个网址会互相影响吗？

不会。每个人的数据保存在自己的浏览器中，彼此独立。只有网页程序文件是所有人共同访问的。
